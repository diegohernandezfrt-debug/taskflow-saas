# SaaS Taskflow

TaskFlow SaaS is a task management web application inspired by tools like Trello and Jira. Allows users to create projects, manage tasks, and organize them using an interactive Kanban box.

Frontend:
[https://TU-FRONTEND.onrender.com](https://taskflow-saas-q4zt.onrender.com)

Backend API:
[https://TU-BACKEND.onrender.com](https://taskflow-api-l8k2.onrender.com)

## ✨ Characteristics

- Registration and login with JWT
- Project management
- Creation, education and elimination of projects
- Creation, education and elimination of tasks
- Kanban board
- Drag and drop to move tasks between states
- Filter and organization of tasks
- Light and dark theme
- Data persistence with PostgreSQL
- REST API
- Deployment in production

## ⚙️ Local installation

### Clone repository

```bash
git clone URL_DEL_REPOSITORY
```

### Install dependencies

```bash
pnpm installation
```

### Configure environment variables

Backend:

```env
URL_DATABASE=
JWT_SECRET=
PORT=4000
```

Frontend:

```env
VITE_API_URL=http://localhost:4000/api
```

### Executive Project

Backend:

```bash
pnpm development
```

Frontend:

```bash
pnpm development
```
